# Polyfork models

3D models in this folder come from Polyfork (https://polyfork.dev), used under
**Creative Commons Attribution 4.0 (CC BY 4.0)**: https://creativecommons.org/licenses/by/4.0/

This repo is public, so only the free mesh files may live here, and every file needs a credit line below.

## Rules
- Allowed here: free GLB, FBX, USD or OBJ files, taken under the CC BY 4.0 option.
- Not allowed here: Polyfork `.mjs` ES modules and HD or Pro editions. They are under the Polyfork licence only,
  which forbids redistributing the files themselves. `.gitignore` blocks `*.mjs` and `hd/` in this folder.
  Keep them outside the repo or fetch them at build time.
- Do not use these models to train a commercial asset generator.
- Licence terms checked on 2026-11-08 at https://polyfork.dev/licensing. Re-check before adding new models.
